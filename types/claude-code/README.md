# types/claude-code

`index.d.ts` is the plugin API's TypeScript declaration file written by Claude Code. Its first line names the Claude Code version that wrote it; `npm run check:types` fails when that differs from the installed `claude --version`. CONTRIBUTING.md says how to refresh it.

It is Anthropic's, not part of this project, and not covered by this repo's MIT licence. It is included only so the plugin type-checks from a fresh clone.
